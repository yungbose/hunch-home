# Hunch Home

Hunch carries out home commands, such as "turn on the reading light", and the same command in your own words,
such as "it's a bit dark in the living room". It joins your assistant as its conversation agent: Home
Assistant's own sentences still answer first, and anything that is not a home command goes to the agent you had
before.

- The model runs inside this app, on this machine. No account, no key, no cloud.
- About 550 MB of memory. 64-bit only: a Raspberry Pi 4 or 5 with a 64-bit system, or a PC.
- English only.

The Documentation tab says how to set it up. The code is Apache 2.0. The model is CC BY-NC 4.0: free for home
and other non-commercial use; commercial use needs permission.
